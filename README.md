# Housing Prices Exploratory Data Analysis (EDA)

## Project Overview
This project performs Exploratory Data Analysis (EDA) on a housing prices dataset to understand the factors affecting property prices.

## Objectives
- Understand the structure of the dataset.
- Identify and handle missing values.
- Remove duplicate records.
- Clean inconsistent data.
- Perform univariate, bivariate, and multivariate analysis.
- Visualize relationships between housing features and sale prices.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset Features
- Number of bedrooms
- Year built
- Zipcode
- Property size
- Garage availability
- Garden availability
- Number of bathrooms
- Sale price

## Data Preprocessing
- Removed duplicate records.
- Handled missing values.
- Converted property size into numeric format.
- Standardized categorical values.
- Created additional features such as property age and price per square foot.

## Analysis Performed
- Univariate Analysis
- Bivariate Analysis
- Multivariate Analysis
- Correlation Analysis
- Data Visualization

## Project Files
- `Housing_Prices_EDA.ipynb` – EDA notebook
- `preprocessed_housing_prices.csv` – Cleaned dataset
- `preprocess_housing_prices.py` – Preprocessing script

## Conclusion
The project demonstrates how data preprocessing and exploratory data analysis can help identify patterns and relationships in housing price data.
